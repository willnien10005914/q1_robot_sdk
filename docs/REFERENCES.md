# References

Q1 Robot SDK is an **original Quanta Computer · MIT Taiwan** platform.

**Education** in this repo means the **developer / secondary-development edition** (tunable motors, PPO, VLA). **Standard** units run predefined motions only; see [editions.md](editions.md).

Public robotics literature on DDS, ROS 2, RL Sim2Sim/Sim2Real, and Vision–Language–Action informed the curriculum structure, but Q1’s mechanical design, QDD actuation stack, 3-finger hand, and transformable wheel-foot morphology are native Quanta MIT designs — not derivatives of other commercial humanoids.
