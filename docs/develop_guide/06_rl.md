# 06 — Reinforcement Learning

Q1 RL follows the Unitree Edu workflow popularized by `unitree_rl_gym`:

```text
Train → Play → Sim2Sim → Sim2Real
```

## Package

```text
rl/q1_rl_gym/
├── envs/           # wheeled loco + arm reach tasks
├── scripts/        # train.py, play.py
└── ...
rl/deploy/
├── sim2sim/        # MuJoCo runner
├── sim2real/       # DDS deploy
└── configs/        # q1_wheeled.yaml, q1_arm_reach.yaml
```

## Tasks (pre-SDK)

| Task id | Description |
|---------|-------------|
| `q1_wheeled` | Track commanded planar velocity on uneven floor |
| `q1_arm_reach` | End-effector reach while base holds |
| `q1_soft_toss` | Gentle underarm toss of a soft ball (sim) |

## Train

```bash
cd rl
python -m q1_rl_gym.scripts.train --task q1_wheeled --headless
```

## Play + export

```bash
python -m q1_rl_gym.scripts.play --task q1_wheeled
# Exports Actor to logs/.../exported/policies/policy_1.pt
```

## Observation sketch (wheeled)

- Base angular velocity (IMU)
- Projected gravity
- Command `(vx, vyaw)`
- Wheel rates
- Previous action
